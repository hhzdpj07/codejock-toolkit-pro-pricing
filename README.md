## $899、$1,099 和每年 $299 分别买的是什么

$899 买的是授权本体，一个开发者，一个技术栈（MFC 版或者 ActiveX 版，二选一），永久使用。

$1,099 是同一份授权加一年维护。维护期内能拿到新版本和技术支持。这 $200 是整份订单里最不该省的一笔，因为控件库这类东西的价值就在持续跟进，Windows 版本更新、编译器和 IDE 升级都会逼着你换版本。

$299 是维护到期后的续费价，一年一次。官方价格页把它单列成 Maintenance Renewal，经销商页面上叫 Subscription Renewal，说的是同一件事。

## 按场景选版本

做 MFC 桌面程序、需要 Ribbon 界面、皮肤、网格、图表这类成套的界面组件，选 Toolkit Pro。这是它的主场，也是官网上那些客户评价反复提到的场景：MFC 程序员想在原生框架上把界面做得像商业软件，又不想自己造轮子。

用 VB6、Delphi、PowerBuilder 这类 ActiveX 容器，或者老系统里通过 COM 调控件，选 Suite Pro。两条产品线价格一模一样，选错的成本是整份授权报废，下单前确认自己项目里用的是哪套。

只缺一个功能，比如就想要个代码编辑器或者就想要换肤，先去看单一控件的报价再回来比。打包价 $899 对单一需求通常不划算。

## 谁不用买 Toolkit Pro

新项目用 WPF、WinUI 或者 Uno 的，直接跳过。Toolkit Pro 服务的是 MFC 和 ActiveX 生态，你的技术栈用不上它。

个人项目、一次性小工具、只给自己或几个同事用的内部程序，$899 很难回本。这类项目用 MFC 自带控件加一两个开源库，界面朴素点但能跑，钱花在别处更值。

团队人数多的，先把席位总价算出来再决定。5 个开发者就是 5 份授权，加上维护，第一年是一笔不小的支出。如果只有一两个人真正动界面代码，其余人只是编译，把席位压到实际需要的数量。

只做后台服务、命令行工具或者驱动，压根没有 GUI，这套东西跟你没关系。

## 客户评价与四个具体限制

官网挂了不少客户评价，署名的有 Henderson Medical Systems 的 Rodney Adams 和 Rane Corporation 的 Alan Christiansen。内容集中在几点：省开发时间、界面看起来专业、示例程序质量不错、论坛里反馈及时。这些话是厂商自己挑出来放在首页的，参考价值有限，但至少方向一致，说的都是"省时间"和"界面观感"，不是"功能最多"。

独立第三方评价我没找到成体系的。能查到的第三方页面主要是经销商 ComponentSource 的商品页，用来核对版本号、席位档位和续费价格很好用，用户评分和深度测评很少。所以下面这几条限制，是我从公开价格和授权结构里读出来的，不是从用户抱怨里总结的。

第一条，按开发者席位计费。这不是按服务器或按终端装，是按写代码的人头。三个人碰这套控件，就得买三份。

第二条，维护要年年续。$299 一年，占含维护首年价的 27%。第一年 $1,099 之后，第二年开始每年 $299，这笔钱要进长期预算，不能只看首年。

第三条，$899 和 $1,099 只差 $200。为省这 $200 放弃一年维护，等于把版本升级和技术支持的通道关掉，后面想补回来可能要重新走一遍采购。

第四条，源码和维护条款要在下单前问清楚。经销商页面上标"含源码"的是带订阅的 1 年续费条目，基础授权是否随附源码，官网价格页没有明确写；退款条款我也没在公开页面确认到具体天数。这两件事一封邮件能问明白，别等付完款再纠结。

还有一点不算缺点但要有心理准备：Toolkit Pro 是 MFC 的扩展库，团队得熟悉 MFC 的消息机制和文档视图结构。不熟 MFC 的人上手这套控件，学习成本在框架本身，不在控件。
